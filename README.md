# InHouseGym — Design 4 Admin Dashboard

This version keeps the customer website, 3 equipment categories, treadmill weight-capacity filtering, product detail pages, cart, login, checkout and rental flow, and replaces the admin area with a separate minimal Design 4 admin interface.

## Run

```bash
npm install
npm run dev
```
## User login

- User registration and login
- Browse and explore gym equipment
- View equipment details and specifications
- Select rental duration
- Add equipment to cart
- Manage cart items
- Enter shipping and contact details
- Upload Aadhaar and PAN card documents
- Select payment method
- Place rental orders
- View order and rental confirmation
